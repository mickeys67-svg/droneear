## 1. 이번 버전의 새로운 기능 (What's New)

ASC 위치: 버전 페이지 상단 → 언어 탭별 입력.

### 🇰🇷 한국어 (374자)

```
• 청취 화면 깜박임 해소 및 안정성 대폭 개선
• 모델이 듣는 소리를 항상 표시 ("듣는 중: 멀티로터 78%")
• 신뢰도 임계값 60%로 낮춤 — 휴대폰 스피커 드론 소리 인식 향상
• 카테고리를 한국어로 표시 (15개 언어)
• 시스템 알림·백그라운드 후 녹음 자동 복구 + 화면 안내
• 지도 화면 위치 권한 자동 갱신
• 새 브랜드 아이콘
• iPhone SE 등 작은 화면 가독성 개선
• 배터리·재개 알림을 비차단 토스트로 변경
• 가이드에 식별 동작 방식 + 좌표계 안내 추가
• 다국어 환경 레이아웃 수정
• 장시간 청취 메모리 최적화
```

### 🇺🇸 English

```
• Eliminated listen-screen flicker, major stability improvements
• Always-on indicator showing what the model is hearing
• Lowered confidence threshold to 60% — better recognition of drone clips played from phone speakers
• Category names now displayed in your language across 15 locales
• Stronger auto-recovery after system audio interruptions, with inline confirmation
• Map screen auto-refreshes when location permission is granted
• New brand icon
• Better readability on small screens (iPhone SE, mini)
• Battery/resume notifications now use non-blocking toasts
• New "How identification works" section in Guide
• Memory optimizations for long scanning sessions
• Numerous multilingual layout fixes
```

## 3. App 심사 정보 — Notes for Reviewer

ASC 위치: 버전 페이지 하단 → "App 심사 정보" 섹션 → "노트(Notes)" 박스.

**영어로 작성** (Apple 리뷰어는 미국 본사).

```
This update bundles 6 micro-releases (2.1.1 through 2.1.6) into one review
cycle. All changes are stability, UX, and i18n improvements — no new
permissions, no new APIs, no business-model changes.

Key user-visible improvements:
- Listen screen no longer flickers; an always-on indicator shows what the
  model is currently hearing
- Category names are now localized across 15 languages
- New brand icon
- Map screen auto-refreshes when Location is granted
- Non-blocking toast notifications replace blocking modal alerts

For testing: launch the app, complete the 6-step onboarding, tap the
microphone button on the main screen. The app is an on-device acoustic
pattern identifier — no audio or location data leaves the device.
```

## 8. 심사 후 (24~48시간 뒤)

### 통과 시 (Pending Developer Release)

ASC → DroneEar → App Store → 2.1.6 페이지 → 오른쪽 위 **"이 버전 출시"** 또는 **"Release This Version"** 클릭.

Phased Release 켜놨으면:
- Day 1: 1% / Day 2: 2% / Day 3: 5% / Day 4: 10% / Day 5: 20% / Day 6: 50% / Day 7: 100%
- 크래시 발견 시 중간에 "Pause Phased Release" 가능

### 리젝 시

ASC → DroneEar → Resolution Center → 리젝 사유 메시지 확인:

| 사유 카테고리 | 대응 |
|---|---|
| **Guideline 2.x (앱 동작)** | 코드 수정 → 새 build → 같은 2.1.6 페이지에 새 build 첨부 → 재제출 |
| **Guideline 4.x (디자인)** | 디자인 수정 후 위와 동일 |
| **Guideline 5.x (개인정보/법적)** | Privacy Manifest, 권한 텍스트, Description 확인 |
