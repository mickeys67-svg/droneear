DroneEar — Drone Detection & Remote ID Scanner

DroneEar detects nearby drones using your smartphone's Bluetooth/WiFi sensors and microphone. All processing happens entirely on your device — no internet connection required, no data leaves your phone.

PRIMARY — Remote ID Detection
- BLE Remote ID (ASTM F3411) on both Android and iOS
- WiFi Remote ID (WiFi Beacon + WiFi NAN) — Android
- Reads a broadcasting drone's serial number, GPS position, altitude, speed and heading
- Shows the drone's real bearing and distance from your location
- Operator location when the drone broadcasts it

SECONDARY — Acoustic Detection (Beta)
- Detects multirotor drone sound using your phone's microphone
- Matches incoming audio against acoustic fingerprints built from real drone recordings
- Acoustic detection indicates a drone-like sound is nearby — it does not provide position
- Support for additional aircraft types is planned for a future update

Other Features
- Real-time map showing Remote ID drone positions
- Detection history
- Environment detection (indoor/outdoor) with adaptive sensitivity
- 3 display themes: Day, Night, AMOLED

15 Languages Supported
Korean, English, Ukrainian, Arabic, Gulf Arabic, Hebrew, Hindi, Urdu, Filipino, German, Spanish, French, Italian, Chinese, Japanese

PRIVACY
- 100% on-device processing
- Zero data collection
- No analytics or tracking
- No internet required
- No account needed

DISCLAIMER
DroneEar is an awareness aid, not a security or safety system. Remote ID detection only works for drones that broadcast Remote ID; many drones do not. Acoustic detection is a probabilistic estimate strongly affected by environment, distance and background noise. Do not rely on DroneEar for safety-critical or security decisions.
