### 🇺🇸 English

```
DroneEar detects nearby drones using your smartphone's Bluetooth
sensor and microphone. All processing happens on your device — no
internet connection required, and no data ever leaves your phone.

TIER 1 — Remote ID Detection
- Detects BLE Remote ID broadcasts (ASTM F3411 standard)
- Reads a broadcasting drone's serial number, GPS position, altitude,
  speed and heading
- Shows the drone's real bearing and distance from your location
- Shows the operator's location when the drone broadcasts it

TIER 2 — Acoustic Detection (Beta)
- Detects multirotor drone sound through the phone microphone
- Matched against acoustic fingerprints built from real drone recordings
- Acoustic detection only signals that a drone-like sound is nearby —
  it does not provide a position
- Support for more aircraft types is planned for future updates

MORE FEATURES
- Real-time map showing the position of Remote ID drones
- Detection history
- Indoor/outdoor environment detection — flags conditions that affect
  detection accuracy
- Three display themes: Day, Night, and AMOLED

15 LANGUAGES
Korean, English, Ukrainian, Arabic, Gulf Arabic, Hebrew, Hindi, Urdu,
Filipino, German, Spanish, French, Italian, Chinese, Japanese

PRIVACY
- 100% on-device processing
- No data collection of any kind
- No analytics, no tracking
- No internet required
- No account required

DISCLAIMER
DroneEar is an awareness aid, not a security or safety system. Remote ID detection only works for drones that broadcast Remote ID, and many drones do not.
Acoustic detection is a probabilistic estimate strongly affected by environment, distance, and background noise.
Do not rely on DroneEar for safety-critical decisions or security purposes.
```

## 4. App 심사 정보 — Notes for Reviewer

```
This release reworks the detection pipeline for accuracy and honesty.

What changed:
- The acoustic classifier was rebuilt as fingerprint matching against
  real drone recordings (validated ~89% balanced accuracy on real audio).
- Acoustic-only distance / bearing / approach-rate estimates were
  REMOVED — they could not be derived reliably from a single
  uncalibrated phone microphone. Position now comes only from BLE
  Remote ID GPS broadcasts.
- The App Store description has been updated to match: claims of
  "hybrid AI", "5 aircraft patterns" and "distance estimation" were
  removed because those features were removed or scoped down.

No new permissions, no new APIs, no business-model changes. The app
remains 100% on-device with zero data collection.

Resubmission note: the App Store description has been revised to
remove all references to other mobile platforms and to describe only
the features available in this iOS build (Guideline 2.3.10).

For testing: launch the app, complete onboarding, tap the microphone
button to start listening. BLE Remote ID detection requires a nearby
drone broadcasting Remote ID; acoustic detection responds to
multirotor-like sound.
```
