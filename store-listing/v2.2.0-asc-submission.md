## 3. App 설명 (Description) — 전면 수정

이전 설명은 제거된 기능(hybrid AI, 5종 식별, 거리/접근율 추정)을 광고하고
있었으므로 실제 동작에 맞게 교체합니다. Play Store와 동일 내용
(`store-listing/android/full-description.txt`).

### 🇺🇸 English

```
DroneEar detects nearby drones using your smartphone's Bluetooth/WiFi
sensors and microphone. All processing happens entirely on your device.

PRIMARY — Remote ID Detection
- BLE Remote ID (ASTM F3411) on Android and iOS
- WiFi Remote ID (Beacon + NAN) — Android
- Reads a broadcasting drone's serial number, GPS position, altitude,
  speed and heading, and shows its real bearing and distance from you

SECONDARY — Acoustic Detection (Beta)
- Detects multirotor drone sound via the phone microphone, matched
  against fingerprints from real drone recordings
- Indicates a drone-like sound nearby — it does not provide position
- More aircraft types planned for a future update

- Real-time map, detection history, 15 languages, 3 themes
- 100% on-device, zero data collection, no account

DISCLAIMER: DroneEar is an awareness aid, not a security or safety
system. Remote ID detection only works for drones that broadcast it;
acoustic detection is a probabilistic estimate affected by environment
and noise. Do not rely on it for safety-critical decisions.
```

## 4. App 심사 정보 — Notes for Reviewer

```
This release reworks the detection pipeline for accuracy and honesty.

What changed:
- The acoustic classifier was rebuilt as fingerprint matching against
  real drone recordings (validated ~89% balanced accuracy on real audio).
- Acoustic-only distance / bearing / approach-rate estimates were
  REMOVED — they could not be derived reliably from a single
  uncalibrated phone microphone. Position now comes only from BLE
  Remote ID GPS broadcasts.
- The App Store description has been updated to match: claims of
  "hybrid AI", "5 aircraft patterns" and "distance estimation" were
  removed because those features were removed or scoped down.

No new permissions, no new APIs, no business-model changes. The app
remains 100% on-device with zero data collection.

For testing: launch the app, complete onboarding, tap the microphone
button to start listening. BLE Remote ID detection requires a nearby
drone broadcasting Remote ID; acoustic detection responds to
multirotor-like sound.
```
